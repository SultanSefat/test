# ScholarMate AI

A bilingual university admissions assistant starter.

## Stack
- Next.js frontend
- Go API
- Redis for knowledge and chat history

## Run locally
1. Start Redis: `docker compose up -d redis`
2. Start API: `cd backend && go run .`
3. Start frontend: `cd frontend && npm install && npm run dev`

Add verified university admission information in the Knowledge panel before using this for real admissions guidance.
